# Content Repurposing

Adapt one approved source into several formats while keeping its meaning, facts and brand voice. The full workflow, with channel guidance and a worked example, is in `content-repurposing/content-repurposing-workflow.md`.

## Before you start

Get or confirm: the source material, the objective, the audience, the channels, tone of voice, the required call to action and anything that must not change or must not be published.

## Steps

1. Read the full source. Note the main message, supporting facts, terminology and anything sensitive.
2. Pick a small number of key messages. Do not try to fit every detail into every format.
3. Map each message to the channel where it works best and the action you want.
4. Write each format separately. Change the opening, length, structure and language for the channel instead of copying the same text.
5. Compare every version with the source and flag any statement that is new, stronger than the source or needs checking.

## Default formats

- **LinkedIn post:** opens with a clear insight, explains why it matters, easy to scan, ends with the approved CTA.
- **Instagram carousel:** cover headline, 5 to 7 slides with one message each, closing slide, short caption.
- **Newsletter section:** subject line, headline, intro, main content, CTA.
- **Short-form video script:** hook, spoken script, on-screen text, closing line, estimated duration.

## Output

The formats above, then for each: the main message used, how it was adapted, what was left out, which claims need verification and whether anything new was introduced. End with a human review checklist.

## Rules

- Use only information from the source and the confirmed facts.
- Do not invent quotes, numbers, examples or features.
- Do not change the meaning or strengthen claims.
- Remove personal and confidential information.
- Every format is a draft until a human approves it.
